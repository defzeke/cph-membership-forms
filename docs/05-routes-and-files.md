# 05 — Routes and files

## Routes

| Path | File | Type | Rendering | Proxy-guarded | Purpose |
| ---- | ---- | ---- | --------- | ------------- | ------- |
| `/` | `app/page.tsx` | page | static | no | Privacy consent gate |
| `/register` | `app/register/page.tsx` | page (server) | dynamic | yes (exempt from the cookie check) | Personal information form |
| `/register/[department]` | `app/register/[department]/page.tsx` | page (server) | dynamic | yes | Role picker + screening questions |
| `/register/[department]/submit` | `app/register/[department]/submit/page.tsx` | page | static, `generateStaticParams` × 9, `dynamicParams = false` | yes | Confirmation + social links |
| `/api/neon-health` | `app/api/neon-health/route.ts` | route handler (`GET`) | dynamic, dev-only | no | Postgres + Object Storage probe (404 in production) |

Valid `[department]` slugs (from `app/register/departments.ts`):

```text
member
administrative-department
people-and-culture-department
business-development-department
creatives-department
marketing-department
operations-department
strategic-planning-department
technology-department
```

`proxy.ts` matches `/register/:path*`, so every route below `/register` runs the guard.
The matcher also covers `/register` itself, which the guard immediately lets through so the
form that *creates* the cookies is never blocked.

Query parameters in use:

| Param | Route | Read by | Meaning |
| ----- | ----- | ------- | ------- |
| `redirect` | `/register` | `register-form.tsx` | Set by the proxy when it bounces a request; only used to show an amber notice |
| `role` | `/register/[department]/submit` | `submission-confirmation.tsx` | Name of the role the applicant applied for; interpolated into the success sentence |

## File-by-file reference

### Root

| File | What it is |
| ---- | ---------- |
| `package.json` | npm manifest. Scripts: `dev`, `build`, `start`, `lint`, `db:migrate`. No `"type": "module"` — the ESM script uses `.mjs`. |
| `package-lock.json` | Lockfile. |
| `next.config.ts` | Empty `NextConfig` (defaults). |
| `tsconfig.json` | `strict`, `moduleResolution: "bundler"`, `jsx: "react-jsx"`, path alias `@/*` → repo root, Next TS plugin. |
| `postcss.config.mjs` | Single plugin: `@tailwindcss/postcss`. |
| `eslint.config.mjs` | Flat config composing `eslint-config-next/core-web-vitals` and `/typescript`, ignoring `.next`, `out`, `build`, `next-env.d.ts`. |
| `proxy.ts` | Next.js 16 proxy: cookie guard for `/register/*`, redirect to `/register?redirect=…`. |
| `neon.ts` | `@neon/config/v1` declaration: realtime preview, `auth: false`, private `assets` bucket, 7-day TTL for new non-default branches. |
| `.gitignore` | Ignores `node_modules`, `.next`, `.env*`, `.neon`, `supabase/`, `next-env.d.ts`, `*.tsbuildinfo`. |
| `AGENTS.md` | Regenerated by `next dev`; contains the Next.js 16 "read the bundled docs" block. Leave it committed. |
| `README.md` | Next.js boilerplate plus a short, accurate "Backend (Neon)" and "Data model" section. |
| `.env.local` *(ignored)* | Written by `neon deploy` / `neon env pull`. See [Getting started](./02-getting-started.md#3-environment-variables). |
| `tsconfig.tsbuildinfo` *(ignored)* | TypeScript incremental build cache. |

### `app/`

| File | Directive | Responsibility |
| ---- | --------- | -------------- |
| `app/layout.tsx` | server | HTML shell, `Geist`/`Geist_Mono` via `next/font/google`, metadata (`CyberPH Membership Registration`), wraps `children` in `LenisProvider`, imports `globals.css`. |
| `app/page.tsx` | `"use client"` | Consent radio group; pushes `/register` only when `consent` is chosen. |
| `app/globals.css` | — | Tailwind import, `@theme` brand tokens, dot-grid + chevron watermark, tri-colour top rule, page-background overrides, header/footer banner pseudo-elements. |
| `app/icon.png` | — | Favicon served by the App Router icon convention. |
| `app/lenis-provider.tsx` | `"use client"` | Creates a `Lenis` instance (`smoothWheel`, `lerp: 0.1`), drives it from `requestAnimationFrame`, destroys on unmount, and no-ops under `prefers-reduced-motion: reduce`. Returns `children` unchanged. |
| `app/register/page.tsx` | server | `dynamic = "force-dynamic"`; `closed={await getClosedSlugs()}` → `RegisterForm`. |
| `app/register/register-form.tsx` | `"use client"` | 11-field form, per-field blur validation, submit-time `safeParse`, cookie read/write, department routing. Wrapped in `Suspense` because it calls `useSearchParams`. |
| `app/register/personal-info.ts` | shared | `registerSchema` (Zod), `RegisterFormValues`, `COOKIE_PREFIX`, `toPersonalInfoRecord`, `registerFieldNames`. Imported by both the browser form and the server action. |
| `app/register/departments.ts` | shared | `Department` type, `DEPARTMENTS` (8 entries with slug/name/description), `getDepartment(slug)`. |
| `app/register/submission-confirmation.tsx` | `"use client"` | Suspense-wrapped `useSearchParams` reader that prints the `?role=` sentence. |
| `app/register/[department]/page.tsx` | server | `dynamic = "force-dynamic"`; validates the slug, redirects if closed, loads roles/questions, renders the form. |
| `app/register/[department]/department-form.tsx` | `"use client"` | Role radios, dynamic questions, native validity check, `submitApplication` call, error panel, success navigation. |
| `app/register/slot-picker.tsx` | `"use client"` | Date + 20-minute time selects; polls `listOpenSlots` every 5 s |
| `app/register/reschedule.tsx` | `"use client"` | Confirmation-page box: booked time and the 5-hour reschedule |
| `app/register/[department]/member-form.tsx` | `"use client"` | General Member page: confirm-to-join button (benefits are announced at onboarding); submits role `Member` with no answers |
| `app/register/[department]/submit/page.tsx` | server | Static confirmation page; `generateStaticParams` from `DEPARTMENTS`; renders social links + `SubmissionConfirmation`. |
| `app/api/neon-health/route.ts` | route handler | `dynamic = "force-dynamic"`; 404 in production; runs a Postgres query and an S3 put/get/delete round trip, returning `{ ok, results }`. |

### `lib/`

| File | Import guard | Responsibility |
| ---- | ------------ | -------------- |
| `lib/pg.ts` | `server-only` | Memoised `pg.Pool` on `globalThis`, rebuilt when `DATABASE_URL` changes. Exports `pool`. |
| `lib/storage.ts` | `server-only` | `S3Client({ forcePathStyle: true })` using ambient `AWS_*` env vars; exports `s3` and `ASSETS_BUCKET = "assets"`. |
| `lib/db.ts` | `"use server"` | `submitApplication(slug, role, answers, interviewAt, team)` — the only write path. Re-validates cookies, one transaction, translated errors. |
| `lib/questions.ts` | none (server-only in practice) | `getClosedSlugs()`, `getRolesAndQuestions(slug)`, `Question` type. |
| `lib/proxy.ts` | none | `registrationGuard.requiredCookies` and `hasRequiredCookies(cookies)`; shared by `proxy.ts`. |

> `lib/questions.ts` has no `server-only` marker even though it opens a database connection.
> It is only imported by server components today, but adding `import "server-only"` would
> make that contract explicit and fail the build if a client component ever imports it.

## Where to look for…

| I need to change… | Go to |
| ----------------- | ----- |
| A validation rule or error message | `app/register/personal-info.ts` |
| A personal-info field | `personal-info.ts` **and** `register-field` markup in `register-form.tsx` |
| What gets written to `registration_personal_info` | `toPersonalInfoRecord` in `personal-info.ts`, plus DB columns in `db/schema.sql` |
| Which cookies gate navigation | `lib/proxy.ts` |
| Contact details / privacy wording | `app/page.tsx` |
| Department names and descriptions | `app/register/departments.ts` |
| Roles and questions | Database rows (`department_roles`, `department_questions`) — see `06-data-model.md` |
| Whether a department is open | `departments.closed` in the database |
| Submit behaviour or error handling | `lib/db.ts` |
| Any read query | `lib/questions.ts` |
| A route's caching behaviour | the `export const dynamic` / `dynamicParams` in that `page.tsx` |
| Colours or brand tokens | `app/globals.css` (`@theme`) |
| Banner art | `public/cyberph/*` + the banner rules in `globals.css` |
| Health checks | `app/api/neon-health/route.ts` |
| Schema or seeds | `db/schema.sql` then `npm run db:migrate` |
